# bloggerapp

This React application was built for **Module 13 (Hands-On Lab 13: Multiple Conditional Rendering Patterns & Keys in List Components)** in the Digital Nurture Java FSE program.

## Features
- **BookDetails Component**: `src/BookDetails.js` displaying books with unique `key={book.id}` props.
- **BlogDetails Component**: `src/BlogDetails.js` displaying blog posts with unique `key={blog.id}` props.
- **CourseDetails Component**: `src/CourseDetails.js` displaying courses with unique `key={course.id}` props.
- **Multiple Conditional Rendering Techniques**: Demonstrates `switch` statement with element variables, logical `&&` short-circuiting, and ternary operators.
