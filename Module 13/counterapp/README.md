# counterapp

This React application was built for **Module 13 (Hands-On Lab 8: React State Management)** in the Digital Nurture Java FSE program.

## Features
- **CountPeople Class Component**: `src/CountPeople.js` managing `entrycount` and `exitcount` in local component state (`this.state`).
- **UpdateEntry() Method**: Increments `entrycount` state when clicking the **Login** button.
- **UpdateExit() Method**: Increments `exitcount` state when clicking the **Exit** button.
