# cohortapp

This React application was built for **Module 13 (Hands-On Lab 5: Styling Components with CSS Modules & Inline Styles)** in the Digital Nurture Java FSE program.

## Features
- **CSS Modules**: Uses `CohortDetails.module.css` defining `.box` class and `dt` tag selector.
- **Dynamic Inline Styles**: Dynamically styles `<h3>` heading font color to **green** for `ongoing` cohorts and **blue** for other statuses.
