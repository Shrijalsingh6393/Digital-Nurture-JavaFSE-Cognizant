# TrainersApp

This React application was built for **Module 13 (Hands-On Lab 6: Client-Side Routing with React Router DOM)** in the Digital Nurture Java FSE program.

## Features
- **Client-Side Routing**: Implemented using `react-router-dom` (`BrowserRouter`, `Routes`, `Route`, `Link`).
- **Trainer Model & Mock Data**: `Trainer.js` and `TrainersMock.js` defining trainer data models.
- **Home Component**: Landing page for Cognizant Trainers System.
- **TrainersList Component**: Displays clickable links navigating to specific trainer details (`/trainers`).
- **TrainerDetails Component**: Dynamically extracts `id` via `useParams()` hook to display detailed trainer profile (`/trainers/:id`).
