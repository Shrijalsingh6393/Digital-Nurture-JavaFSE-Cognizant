# StudentApp - Student Management Portal

This React application was built for **Module 13 (Hands-On Lab 2: React Components)** in the Digital Nurture Java FSE program.

## Features
- **Home Component**: Displays `Welcome to the Home page of Student Management Portal`
- **About Component**: Displays `Welcome to the About page of the Student Management Portal`
- **Contact Component**: Displays `Welcome to the Contact page of the Student Management Portal`
- Demonstrates ES6 Class Components inheriting from `React.Component` and using the `render()` method.
