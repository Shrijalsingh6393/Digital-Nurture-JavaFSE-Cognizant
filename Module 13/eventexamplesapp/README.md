# eventexamplesapp

This React application was built for **Module 13 (Hands-On Lab 11: React Events, Synthetic Events, Argument Passing, and Currency Converter)** in the Digital Nurture Java FSE program.

## Features
- **Multi-Method Execution**: **Increment** button invokes `incrementValue()` and `sayHello()` static welcome alert message.
- **Argument Passing**: **Say Welcome** button passes `'welcome'` argument to `sayWelcome(msg)`.
- **Synthetic Event OnPress**: Button handling `SyntheticEvent` and displaying `"I was clicked"`.
- **CurrencyConvertor Component**: `src/CurrencyConvertor.js` converting Rupees (INR) to Euro (EUR) on form submission.
