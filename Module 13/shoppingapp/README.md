# shoppingapp

This React application was built for **Module 13 (Hands-On Lab 7: Props, Default Props, and Item Rendering)** in the Digital Nurture Java FSE program.

## Features
- **Cart Class Component**: `src/Cart.js` accepting `Itemname` and `Price` as props, with `defaultProps` fallback.
- **OnlineShopping Class Component**: `src/OnlineShopping.js` maintaining an array of 5 shopping cart items and mapping over them to render `<Cart />` table rows.
