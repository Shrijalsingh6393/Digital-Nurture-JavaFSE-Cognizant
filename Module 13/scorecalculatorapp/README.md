# scorecalculatorapp

This React application was built for **Module 13 (Hands-On Lab 3: Function Components & Component Styling)** in the Digital Nurture Java FSE program.

## Features
- **CalculateScore Component**: Functional component accepting `Name`, `School`, `Total`, and `goal` props.
- Calculates and formats score percentage using `calcScore` and `percentToDecimal` functions.
- Custom CSS styling applied via `src/Stylesheets/mystyle.css`.
