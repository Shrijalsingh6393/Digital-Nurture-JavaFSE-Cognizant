# ticketraisingapp

This React application was built for **Module 13 (Hands-On Lab 15: React Forms & Controlled Components)** in the Digital Nurture Java FSE program.

## Features
- **Controlled Components**: `src/ComplaintRegister.js` binding Employee Name (`ename`) textbox and Complaint (`complaint`) textarea to local component state.
- **Form Submission & Handlers**: Prevents default page reload with `e.preventDefault()`, generates a random Reference Number / Transaction ID, and displays a confirmation alert box.
