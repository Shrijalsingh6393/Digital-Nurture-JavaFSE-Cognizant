# ticketbookingapp

This React application was built for **Module 13 (Hands-On Lab 12: Conditional Rendering & Element Variables)** in the Digital Nurture Java FSE program.

## Features
- **Conditional Rendering**: Uses Element Variables (`let pageContent`, `let authButton`) to switch views based on authentication state (`isLoggedIn`).
- **Guest View**: `src/GuestPage.js` displaying flight schedules in read-only mode.
- **User View**: `src/UserPage.js` allowing authenticated users to book flight tickets.
