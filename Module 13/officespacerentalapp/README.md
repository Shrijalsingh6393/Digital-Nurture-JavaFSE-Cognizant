# officespacerentalapp

This React application was built for **Module 13 (Hands-On Lab 10: JSX Syntax, Image Attributes, JavaScript Expressions, and Dynamic Inline CSS)** in the Digital Nurture Java FSE program.

## Features
- **JSX Heading Element**: Displays `<h1>Office Space , at Affordable Range</h1>`.
- **Image Attributes**: `<img src="..." alt="Office Space" width="320" height="200" />`.
- **Single Office Object**: Renders `Name`, `Rent`, and `Address` properties.
- **Office List Iteration**: Maps over an array of office objects.
- **Dynamic Inline CSS**: Displays rent font color in **Red** if rent $\le 60000$ and **Green** if rent $> 60000$.
