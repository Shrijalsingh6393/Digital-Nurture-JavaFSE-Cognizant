# mailregisterapp

This React application was built for **Module 13 (Hands-On Lab 16: Form Validation in React)** in the Digital Nurture Java FSE program.

## Features
- **Register Component**: `src/Register.js` accepting Name, Email, and Password.
- **Real-Time & Submission Validation**:
  1. **Name**: Validation requires at least 5 characters (`Name should have at least 5 characters`).
  2. **Email**: Validation requires `@` and `.` (`Email should contain @ and .`).
  3. **Password**: Validation requires at least 8 characters (`Password should have at least 8 characters`).
